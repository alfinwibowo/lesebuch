# Lesebuch

Kurze Geschichten auf Deutsch, nach Stufen 1–5, mit englischer Übersetzung und Audio.

Geschichten: [Global Storybooks – Geschichten auf Deutsch](https://global-asp.github.io/storybooks-german/) und das African Storybook, Lizenz [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Bilder und Audio werden direkt von dort geladen.

## Veröffentlichen
1. Neues öffentliches Repository `lesebuch` auf GitHub anlegen.
2. Alle Dateien aus diesem Ordner hochladen (Add file → Upload files) → Commit changes.
3. Settings → Pages → Branch `main`, `/ (root)` → Save.
4. Auf dem iPhone `https://<dein-name>.github.io/lesebuch/` in Safari öffnen → Teilen → Zum Home-Bildschirm.
